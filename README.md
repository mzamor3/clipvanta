# ClipVanta AI

A static MVP landing page and faceless-video planning demo.

## Deploy on Vercel
1. Unzip this folder.
2. In Vercel, choose "folder" on the New Project screen.
3. Select the unzipped `clipvanta-site` folder.
4. Deploy.
5. After deployment, add `clipvanta.com` in Vercel Project Settings → Domains.
6. Vercel will show the DNS records to add in Cloudflare.

## Notes
- The generator currently runs in demo mode with no API key.
- Stripe and real AI generation can be connected later.
